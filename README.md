## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Tracker** | Organize Kdenlive projects with version and delivery status |
| **Effects Library** | Document custom effect chains and their project usage |
| **Render Queue** | Manage and prioritize Kdenlive render queue with output settings |
| **Clip Organizer** | Track project clips with source, resolution and usage notes |
